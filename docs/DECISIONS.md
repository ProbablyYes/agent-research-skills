# V0.1 decisions — subject to review

**Adopt**: observations vs hypotheses, competing predictions, evidence provenance, independence, experimental unit, reproducibility metadata, cost guards.

**Modify**: workflows are optional capabilities, not mandatory stages; no fixed number of alternative hypotheses or single global project stage.

**Reject by default**: numeric novelty gates, compulsory forms, automatic Accept/Reject decisions, schema validity presented as scientific validity, automatic paid experiments.

**Not yet imported**: upstream Python scripts, RW Passport, external API integrations, Supervisor-Skills files. Future upstream reuse requires explicit file-level license, version, code/security review and test records.

## Proposed behavioral assessment
Use matched tasks for (A) base Codex, (B) upstream, (C) concise modified skill, (D) expanded local skill. Blindly audit claim fidelity, discriminating test quality, unsupported causal claims, false rejections and latency/token costs.
